# Vendored Swagger UI

`swagger-ui-bundle.js` and `swagger-ui.css` are unmodified distribution assets
from https://github.com/swagger-api/swagger-ui/tree/v5.33.1/dist.
Apache-2.0 license and upstream NOTICE are included. Update these together when
upgrading. The HTML and initializer are maintained by Transfer Engine.

SHA-256 of the downloaded distribution assets:

- `swagger-ui-bundle.js`: `050bc415ee7048dcd881682678f720264e7da5e373f7461d7c58c755305255f7`
- `swagger-ui.css`: `1ac324f7dcd27e4b9386b4bd6421271ec147e922a22c05ba24b11515e9aa6321`

Assets and the OpenAPI document are embedded; no CDN or external validator is
used at runtime. Authorization is kept in memory, not persisted across reloads.
